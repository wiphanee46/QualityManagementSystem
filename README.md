# Quality Management System

ระบบจัดการปัญหาลูกค้าและวิเคราะห์ข้อมูลคุณภาพ

## Project 01: Customer Complaint Tracking System

ระบบบันทึกและติดตามปัญหาที่ได้รับแจ้งจากลูกค้า

Features:
- บันทึกปัญหาลูกค้า
- จัดประเภทปัญหา
- ระบุผู้รับผิดชอบ
- ติดตามสถานะการแก้ไข
- บันทึกประวัติการดำเนินงาน

## Project 02: Quality Data Dashboard

ระบบวิเคราะห์ข้อมูลคุณภาพ

Features:
- วิเคราะห์ปัญหาคุณภาพ
- แสดง Top 10 Problems
- วิเคราะห์ปัญหารายเดือน
- วิเคราะห์ข้อมูลแยกตามลูกค้า
- แสดงกราฟแนวโน้ม
